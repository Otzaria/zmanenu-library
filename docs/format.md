# פורמט המקור

מקור הספרים יושב בתיקייה אחת: `source/` לספרים האמיתיים, ו-`examples/` לדוגמה. לשתיהן אותו מבנה:

```
source/
├── books/                      תיקייה = קטגוריה, קובץ = ספר
│   └── הלכה/שבת/<כותרת>.txt
├── metadata.json               פרטי ספר: תיאור, מחבר, סדר, דור, ראשי תיבות...
├── categories.json             פרטי קטגוריה: סדר ותיאור
├── links/<כותרת>_links.json    קישורים: פנימיים ולספרייה הרשמית
├── alt_toc/<כותרת>_alt_toc.json  כותרות חלופיות (לשונית "כותרות")
├── versions.csv                ספר כגרסה של ספר אחר
├── editions/<כותרת>/           מהדורות: נוסח חלופי שורה מול שורה
├── default_commentators.json   מפרשי ברירת מחדל
└── default_targumim.json       תרגומי ברירת מחדל
```

כל הקבצים פרט ל-`books/` אופציונליים, וכולם ב-UTF-8. רוב הפורמט זהה לספריית אוצריא הרשמית
(otzaria-library): עץ התיקיות, `<h1>`…`<h6>`, `metadata.json`, `links/*_links.json`, `alt_toc/*_alt_toc.json`,
`default_commentators.json`. `versions.csv` זהה לקובץ `גרסאות.csv` של ספרים אישיים באוצריא.

הבונה עוצר על כל אי-התאמה, כמו כותרת שאינה קיימת, שורה מחוץ לטווח, מפתח לא מוכר או דור לא מוכר, ומדפיס
את הקובץ ואת הרשומה.

## ספרים וקטגוריות — `books/`

- כל תיקייה תחת `books/` היא קטגוריה, וקטגוריות מקוננות לפי עומק התיקיות. באוצריא הן מוצגות בתוך התיקייה
  העליונה "מחברי זמננו" (`library_folder`).
- כל ספר חייב לשבת בתוך תיקייה: קובץ שיושב ישירות תחת `books/` הוא שגיאה.
- **שם הקובץ בלי הסיומת הוא כותרת הספר.** הכותרת חייבת להיות ייחודית בכל המסד, כי קישורים, מטא-דאטה
  וגרסאות מתייחסים לספר לפי הכותרת.
- `"` אסור בשמות קבצים ב-Windows. כותבים `״` (U+05F4), למשל `תנ״ך`, ובאותו אופן גם `׳`.
- קבצים ותיקיות שמתחילים בנקודה, וכן `README.md`, אינם נקראים.

### ספר טקסט — `.txt`

- כל שורה בקובץ היא שורה בספר (`line`). בקובצי המקור השורות נספרות מ-1, ובמסד מ-0.
- מותר HTML כמו בספרייה הרשמית: `<b>`, `<i>`, `<small>`, `<sup>` וכו'.
- **כותרות:** שורה שמתחילה ב-`<h1>`…`<h6>` היא כותרת. היא נכנסת לתוכן העניינים, והקינון נקבע לפי הרמה.
  השורה עצמה נשארת שורה בספר. כותרת ריקה היא שגיאה. נהוג שהשורה הראשונה תהיה `<h1>כותרת הספר</h1>`.
- `line.heRef` נקבע כמו בספרי אוצריא הרשמיים: `"<כותרת> <מספר שורה>"`, בשורות שאינן כותרת. ממנו נבנה `line_ref`
  (איתור מקור עד השורה).

```
<h1>קיצור הלכות שבת לדוגמה</h1>
<h2>פרק א - הדלקת נרות</h2>
מצוה להדליק נרות שבת קודם השקיעה.
```

### רק ספרי טקסט

המסד מכיל ספרי טקסט בלבד. קובץ שאינו טקסט בכל מקום בעץ המקור הוא שגיאה: ב-`books/` מותר רק `.txt`,
ובשאר המקומות רק `.txt`, `.json`, `.csv` ו-`.md`. הקבצים `desktop.ini` ו-`Thumbs.db`, ש-Windows יוצר
בתיקיות, אינם נקראים.

## `metadata.json` — פרטי ספר

אובייקט לפי כותרת הספר. אפשר גם מערך של אובייקטים עם `"title"`, כמו בספרייה הרשמית. כל השדות אופציונליים:

| שדה | טבלה במסד | הערה |
|---|---|---|
| `heShortDesc` | `book.heShortDesc` | תיאור קצר |
| `heDesc` | `book.heDesc` | תיאור מלא |
| `author` / `authors` | `author` + `book_author` | מחרוזת או רשימה |
| `order` | `book.orderIndex` | מספר; ברירת מחדל 999, אחר כך לפי כותרת |
| `pubDate`, `pubPlace` | `pub_date`, `pub_place` | |
| `generation` | `generation` + `book_generation` | אחד מ: `תורה שבכתב`, `חז"ל`, `ראשונים`, `אחרונים`, `מחברי זמננו`. בלעדיו: `default_generation` מ-`library.json` (`מחברי זמננו`). זה מה שמקבץ מפרשים לפי דור. |
| `acronyms` | `book_acronym` | ראשי תיבות וכינויים לחיפוש ולאיתור |
| `topics` | `topic` + `book_topic` | ברירת מחדל: שתי התיקיות האחרונות, כמו ברשמית |
| `dibburHamatchil` | `line_dh` | `true`: הקטע המודגש (`<b>`) שבתחילת כל שורה הוא "דיבור המתחיל" |
| `isBaseBook` | `book.isBaseBook` | ספר בסיס; מסומן לבד כשיש לו מפרשים |
| `renamedFrom` | — | שמות קודמים של הספר, לשמירת המזהה (ראו בהמשך) |

```json
{
  "קיצור הלכות שבת לדוגמה": {
    "heShortDesc": "הלכות שבת בקצרה",
    "author": "מחבר לדוגמה",
    "order": 1,
    "acronyms": ["קהש\"ד"]
  },
  "ביאור על קיצור הלכות שבת לדוגמה": { "dibburHamatchil": true, "generation": "מחברי זמננו" }
}
```

### שינוי שם של ספר

מזהה הספר במסד (`book.id`) הוא זהותו באוצריא: אינדקס החיפוש, הסימניות וה-`bookUid` של תוספים נשענים עליו.
בכל רילייס הבונה מקבל את המסד הקודם, וכל ספר שומר את המזהה שהיה לו לפי הכותרת. ספר חדש מקבל מזהה
שמעולם לא היה בשימוש. בשינוי שם של ספר שכבר פורסם, מוסיפים את השם הישן:

```json
{ "הכותרת החדשה": { "renamedFrom": ["הכותרת הישנה"] } }
```

בלי זה הספר יקבל מזהה חדש, והסימניות עליו ייעלמו. הערות אישיות באוצריא נשמרות לפי כותרת, ולכן הן אובדות
בשינוי שם בכל מקרה.

## `categories.json` — פרטי קטגוריה

אובייקט לפי נתיב התיקייה מתחת ל-`books/`, עם `/` בין הרמות:

```json
{
  "הלכה": { "order": 1, "heShortDesc": "ספרי הלכה" },
  "הלכה/שבת": { "order": 1, "heShortDesc": "הלכות שבת", "heDesc": "תיאור ארוך" }
}
```

## `links/<כותרת>_links.json` — קישורים

אותו פורמט כמו `links/` בספרייה הרשמית: מערך, לכל ספר מקור קובץ משלו. אינדקסי השורות **מתחילים מ-1**.

| שדה | חובה | משמעות |
|---|---|---|
| `line_index_1` | ✓ | השורה בספר של הקובץ |
| `path_2` או `book_2` | ✓ | ספר היעד: שם קובץ/נתיב (כמו ברשמית), או הכותרת ישירות |
| `line_index_2` | ✓ (פנימי) | השורה בספר היעד |
| `Conection Type` | | סוג הקישור, כמו ברשמית (כולל שגיאת הכתיב). אפשר גם `connection_type`. ריק = `other` |
| `heRef_2` | | הפניית היעד |
| `line_index_1_end`, `line_index_2_end` | | סוף טווח (כולל), לקישור שמכסה כמה שורות |
| `start`, `end` | | עוגן מילה: היסט תווים בשורת המקור כפי שהיא בקובץ, כולל תגיות |
| `target_library` | | קישור למסד אחר; ראו בהמשך |

**משמעות הסוג:** "היעד הוא X ביחס לספר של הקובץ". `commentary` אומר שהיעד הוא פירוש על הספר שלי, ו-`source`
אומר שהיעד הוא המקור של הספר שלי. בדרך כלל משתמשים ב-`source` בקובץ של הפירוש, וב-`commentary` או `targum` בקובץ של ספר הבסיס.
כמו בבונה הרשמי, `source` נשמר הפוך: כקישור `COMMENTARY` מספר הבסיס אל הפירוש, כדי שהפירוש יופיע בחלונית
המפרשים. סוגים מוכרים: `commentary`, `targum`, `reference`, `source`, `midrash`, `quotation`, `mesorat hashas`,
`ein mishpat`, `dibur hamatchil`, `parshanut`, `mishnah in talmud`, `related`, `footnotes`, `sifrei mitzvot`,
`essay`, `allusion`, `liturgy`, `elucidation`, `explication`, `law`, `summary`, `other`.

קישור לשורת כותרת, לשורה מחוץ לספר או לספר שאינו קיים הוא שגיאה.

```json
[
  { "line_index_1": 3, "line_index_2": 3, "path_2": "קיצור הלכות שבת לדוגמה.txt",
    "heRef_2": "קיצור הלכות שבת לדוגמה 3", "Conection Type": "source" },
  { "line_index_1": 7, "line_index_2": 7, "line_index_2_end": 9,
    "book_2": "קיצור הלכות שבת לדוגמה", "Conection Type": "source" }
]
```

### קישור לספרייה הרשמית או למסד אחר — `target_library`

רשומה עם `target_library` נכנסת לטבלה `external_link`, לא ל-`link`:

| `target_library` | היעד |
|---|---|
| `official` (או `רשמי`) | ספר בספרייה הרשמית |
| `<library_id>` של מסד אחר | ספר במסד מצורף אחר |
| `any` (או `כל`) | הרשמית קודם, אחר כך מסדים מצורפים לפי עדיפות |

- `book_2` (או `path_2`) הוא כותרת הספר ביעד, בדיוק כפי שהיא שם.
- `heRef_2` הוא ההפניה ביעד, **מועדפת**, כפי שהיא מופיעה ב-`line.heRef` של הספרייה הרשמית, למשל `בראשית, א, א`. בלעדיה נדרש
  `line_index_2` (מ-1).
- כדי שהספר שלכם יופיע בחלונית המפרשים של ספר רשמי, כתבו `"Conection Type": "source"`: מבחינת הפירוש שלכם, הספר הרשמי הוא המקור.
  כאן הסוג **אינו** מתהפך. זו ההגדרה של `external_link` באוצריא.
- הבונה אינו רואה את הספרייה הרשמית. `--official-db <seforim.db>` בבנייה מקומית בודק שהכותרות קיימות.
- טווחים ועוגנים אינם נתמכים ב-`external_link`, ומתעלמים מהם עם אזהרה.

```json
[ { "line_index_1": 3, "target_library": "official", "book_2": "בראשית",
    "heRef_2": "בראשית, א, א", "Conection Type": "source" } ]
```

## `alt_toc/<כותרת>_alt_toc.json` — כותרות חלופיות

אותו פורמט כמו ברשמית. מערך מבנים, ובכל מבנה עץ צמתים. `line` נספר מ-1, וכל שורה משויכת לצומת האחרון
שלפניה (`line_alt_toc`).

```json
[ { "key": "topics", "title": "Topics", "heTitle": "לפי נושא",
    "nodes": [ { "heTitle": "ערב שבת", "line": 3,
                 "children": [ { "heTitle": "הדלקת נרות", "line": 3 } ] } ] } ]
```

## `versions.csv` — ספר כגרסה של ספר אחר (`book_version_link`)

אותן עמודות כמו `גרסאות.csv` באוצריא: `ראשי,גרסה,שם,הערות,עדיפות,מקור_ראשי,קטגוריית_ראשי`.
`גרסה` היא כותרת ספר **במסד הזה**. אוצריא מסתירה אותו מהעץ ומציגה אותו בגרסאות של הספר הראשי.

| `מקור_ראשי` | הספר הראשי | |
|---|---|---|
| ריק / `רשמי` / `official` | בספרייה הרשמית | **שימו לב:** ב-`גרסאות.csv` של אוצריא ריק פירושו "אישי". כאן ריק פירושו רשמי, כמו בטבלה |
| `מסד זה` / `local` | במסד הזה (נבדק שהוא קיים) | |
| `db:<library_id>` / `מסד:<id>` | במסד מצורף אחר | |
| `אישי` / `user` | בספרים האישיים של המשתמש | |

```csv
ראשי,גרסה,שם,הערות,עדיפות,מקור_ראשי,קטגוריית_ראשי
קיצור הלכות שבת לדוגמה,קיצור הלכות שבת לדוגמה - נוסח מקוצר,נוסח מקוצר,,1,מסד זה,
משנה ברורה,משנה ברורה - מהדורה מוערת,מהדורה מוערת,,1,רשמי,
```

## `editions/<כותרת>/` — מהדורות (`book_version` + `version_line`)

נוסח חלופי של **אותו** ספר, שורה מול שורה, למשל מהדורה מנוקדת. בורר הגרסאות בקורא מחליף ביניהן.

- `editions/<כותרת>/<שם המהדורה>.txt`: חייב להכיל בדיוק את מספר השורות של הספר, ואת שורות הכותרת זהות.
- `editions/<כותרת>/editions.json`, אופציונלי: פרטים לכל מהדורה, ו-`base` לנוסח שב-`books/`.

```json
{ "base": { "title": "נוסח רגיל", "source": "כתב יד המחבר" },
  "מהדורה מנוקדת": { "source": "...", "license": "CC0", "notes": "...", "priority": 50 } }
```

## `default_commentators.json`, `default_targumim.json` — ברירות מחדל

אותו פורמט כמו ברשמית. המיקום ברשימה הוא ה-`position`, ו-`"-"` משאיר מקום ריק. שני הצדדים חייבים להיות ספרים
**במסד הזה**: אוצריא קוראת את הטבלה רק בתוך אותו מסד.

```json
[ { "book": "קיצור הלכות שבת לדוגמה", "commentators": ["ביאור על קיצור הלכות שבת לדוגמה"] } ]
```

```json
[ { "book": "קיצור הלכות שבת לדוגמה", "targumim": ["קיצור הלכות שבת לדוגמה - תרגום"] } ]
```

## `library.json` — זהות המסד

נכנס ל-`schema_meta`. **אין לשנות את `library_id`, `update_manifest_url` ו-`update_public_key`**, ראו README.

| מפתח | ערך |
|---|---|
| `library_id` | `otzaria.zmanenu` |
| `library_name` | שם התצוגה: `מחברי זמננו` |
| `library_folder` | התיקייה העליונה בעץ: `מחברי זמננו` |
| `update_manifest_url` | `https://github.com/Otzaria/zmanenu-library/releases/latest/download/manifest.json` |
| `update_public_key` | המפתח הציבורי (ed25519, base64) |
| `default_generation` | דור לספר שלא הוגדר לו דור |
| `db_file_name` | שם קובץ המסד |
| `description`, `author` | לידיעה |

`db_version` אינו כתוב כאן: ה-workflow קובע אותו בכל רילייס (הגרסה האחרונה + 1).

## מה לא נתמך

- **טבלאות שאוצריא קוראת ממסד אישי, אבל הבונה עוד לא מייצר:** `link_suppressed_side` (הסתרת צד של קישור, תוצר של
  אלגוריתם הניקוי של הבונה הרשמי), `line_note`/`line_note_divine_name` (הערות שוליים כטבלה), `line_divine_name`
  (סימון שמות קודש), `banner`/`book_banner` ו-`book_protection` (באנר והגנת מו"ל). הערות שוליים אפשר לכתוב כבר עכשיו
  בתוך הטקסט ב-HTML. ראו את השאלות הפתוחות.
- **מפרש ברירת מחדל לספר רשמי, או מפרש רשמי כברירת מחדל לספר שלנו:** `default_commentator` נקרא רק בתוך אותו מסד.
