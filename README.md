# מחברי זמננו

מסד ספרים אישי רשמי של אוצריא. הריפו מחזיק את **מקור** הספרים בפורמט נוח לעריכה, ובונה
ממנו קובץ SQLite בפורמט `seforim.db` (`zmanenu.db`). משתמשים מצרפים את הקובץ לאוצריא
כ"מסד ספרים אישי מצורף", והוא מוצג בעץ הספרייה כתיקייה עליונה בשם **"מחברי זמננו"**.
עדכונים מגיעים אליהם חתומים, דרך GitHub Releases.

| מה | איפה |
|---|---|
| זהות המסד (`library_id`, שם, תיקייה, כתובת עדכונים, מפתח ציבורי) | [`library.json`](library.json) |
| מקור הספרים האמיתי (מתחיל ריק) | [`source/`](source) |
| דוגמה מלאה לכל יכולת | [`examples/`](examples) — אפשר למחוק |
| מדריך הפורמט המלא | [`docs/format.md`](docs/format.md) |
| הוצאת גרסה, מפתח וסוד | [`docs/release.md`](docs/release.md) |
| הבונה (Dart) ובדיקותיו | [`builder/`](builder) |
| CI | [`.github/workflows/`](.github/workflows) |

## ⚠️ אסור לשנות לעולם

- **`library_id` = `otzaria.zmanenu`**. עליו נשענים הסימניות, ההערות, ההיסטוריה ואינדקס
  החיפוש של כל משתמש. שינוי יוצר "מסד חדש", וכל העדכונים לעותקים קיימים נדחים.
- **`update_manifest_url`** ו-**`update_public_key`** ב-`library.json`. אוצריא נועצת אותם
  בפעם הראשונה שהיא רואה את המסד. ערך אחר יגרום לכך שכל המשתמשים יפסיקו לקבל עדכונים, עד
  שיסירו את המסד ויצרפו אותו מחדש.
- **המפתח הפרטי** (`ZMANENU_SIGNING_KEY`). אין החלפת מפתח. אם הוא אובד, אי אפשר להוציא עוד
  עדכון לאף משתמש. שמרו גיבוי מחוץ ל-GitHub. המפתח לעולם לא נכנס לריפו.
- **כותרת של ספר שכבר פורסם.** מזהה הספר נקבע לפי הכותרת. בשינוי שם, הוסיפו את השם הישן ל-`renamedFrom`
  ב-`metadata.json`, ראו [`docs/format.md`](docs/format.md#שינוי-שם-של-ספר).
- אל תמחקו רילייסים ישנים: הבנייה הבאה מורידה מהם את המסד הקודם, כדי לשמור את מזהי הספרים ולייצר
  תיקוני דלתא.

## הוספת תוכן — בקצרה

הכול תחת `source/`. הפורמט זהה לספריית אוצריא הרשמית ככל האפשר: תיקייה היא קטגוריה,
קובץ `.txt` הוא ספר, ו-`<h1>`…`<h6>` הן תוכן העניינים.

- **תיקייה (קטגוריה):** יוצרים תיקייה תחת `source/books/`. הסדר והתיאור נכתבים ב-`source/categories.json`.
- **ספר:** קובץ `source/books/<קטגוריה>/<כותרת הספר>.txt` (UTF-8). שם הקובץ הוא כותרת הספר.
  ספר ישירות ב-`source/books/` מוצג ישירות בתוך "מחברי זמננו".
  פרטים כמו מחבר, תיאור, סדר ודור נכתבים ב-`source/metadata.json`.
  המסד מכיל **ספרי טקסט בלבד**: קובץ שאינו טקסט (PDF, DOCX, תמונה) בתוך `source/` הוא שגיאה.
  במקום `"` בשם קובץ או תיקייה כותבים `״` (גרשיים עבריים). Windows אינו מתיר `"`.
- **קישור** (פירוש, תרגום, הפניה, וגם לספר בספרייה הרשמית): `source/links/<כותרת>_links.json`.
- **גרסה של ספר אחר:** שורה ב-`source/versions.csv`. **מהדורה** (נוסח חלופי שורה מול שורה): `source/editions/<כותרת>/`.

כל סוג נתון מתועד עם דוגמה ב-[`docs/format.md`](docs/format.md), ויש לו קובץ חי מקביל ב-`examples/`.

## בנייה מקומית

דרוש Dart 3.9 ומעלה (מגיע עם Flutter).

```bash
cd builder
dart pub get
dart test                                   # בדיקות הבונה
dart run bin/zmanenu.dart build --source ../source   --out ../dist --db-version 1
dart run bin/zmanenu.dart build --source ../examples --out ../dist-examples --db-version 1
```

- `--library` ברירת מחדל: `library.json` שליד תיקיית המקור.
- `--previous-db <old.db>` שומר את מזהי הספרים מגרסה קודמת. ה-workflow עושה זאת לבד.
- `--official-db <seforim.db>` בודק שכל קישור ל`official` מצביע על ספר שקיים בספרייה הרשמית.

כל שגיאה מודפסת עם הקובץ והרשומה, למשל `שגיאה: links/X_links.json [3]: ספר היעד "Y" לא קיים במסד`.
כשיש שגיאה, לא נכתב מסד.

הפלט: `dist/zmanenu.db`. כדי לנסות באוצריא: הגדרות ← ספרייה ← "מסדי ספרים אישיים" ← הוספת הקובץ.

אימות מול כלי האפליקציה (מתוך ריפו של אוצריא):

```bash
dart run tool/validate_personal_db.dart /path/to/dist/zmanenu.db
```

## הוצאת גרסה

Actions ← **Release** ← Run workflow. הפרמטרים: הערות גרסה, מספר הגרסאות שיקבלו דלתא (ברירת מחדל 3),
ו-`db_version` ידני (אופציונלי). ה-workflow בונה, מאמת, מעלה את `db_version`, אורז עם דלתות, חותם,
מאמת את החתימה ומפרסם רילייס `vN`. פירוט מלא, כולל הגדרת הסוד: [`docs/release.md`](docs/release.md).

ה-workflow **Check** רץ על כל push ו-PR: בדיקות, בנייה של `source/` ושל `examples/`, ואימות. הוא אינו מפרסם.

## לפני ההפצה הראשונה

1. מחקו את `examples/`, או השאירו אותה. היא נבנית רק ב-Check ואינה נכנסת לרילייס.
2. הכניסו ספרים ל-`source/`.
3. הגדירו את הסוד `ZMANENU_SIGNING_KEY` ([`docs/release.md`](docs/release.md#הגדרת-הסוד)).
4. הריצו Release.
